# bagas-sec-portfolio

Bagaskara // Security Researcher

Personal portfolio — Next.js 15 App Router, TypeScript, Tailwind, glassmorphism.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React
- JetBrains Mono

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Connect this repo to Vercel. Root directory is the project root. No env vars required.

Expected production URL: `https://bagas-sec-portfolio.vercel.app`
